> Pipeline ETL retail avec contrôle qualité, modèle en étoile et KPIs SQL

**Stack :** Python, Pandas, SQLite, SQL, Streamlit
**Objectif :** transformer un export de ventes brut en indicateurs métier fiables
**Rendu :**

- Projet 100 % reproductible (aucune clé d'API requise)
